Neurips SEA 2025 EVOLVE-MEM: A Self-Adaptive Hierarchical Memory Architecture for Next-Generation Agentic A/ Systems Rishi Shah, Ujjwal Kakkar, Shashvat Singhal, Dinesh Kumar Vishwakarma Modern Al agents often struggle with long-term memory, evolving knowledge, and sustained reasoning due to fixed context windows and static memory architectures. To address these challenges, we propose EVOLVE-MEM, a self-adaptive hierarchical memory framework that enables continuous learning, efficient knowledge organization, and dynamic memory evolution. The architecture is built around three interconnected components: a Dynamic Memory Network for semantic experience storage, a Hierarchical Memory Manager that organizes information into multiple abstraction levels using adaptive clustering and large language models, and a Self-Improvement Engine that continuously monitors system performance and autonomously reorganizes memory when required. By combining multi-level retrieval, intelligent memory routing, and an answer-patching mechanism, the framework supports accurate temporal, causal, and multi-hop reasoning while maintaining efficient retrieval. Experimental evaluation on the LoCoMo benchmark demonstrates that EVOLVE-MEM consistently outperforms existing memory-based agent architectures, achieving 58.3% overall accuracy across five reasoning categories. Its modular and adaptive design establishes a scalable foundation for next-generation autonomous Al agents capable of continuous learning in dynamic real-world environments. ACL SAW 2026 CBAL: Context-Based Agentic Learning for Speaker Diarization Segmentation Odwitiyo Dutta, Dinesh Kumar Vishwakarma Speaker diarization systems often produce segmentation errors such as false speaker splits, boundary misplacements, and short-turn ambiguities, which reduce transcript readability and negatively impact downstream speech processing applications. To address these challenges, we propose CBAL (Context-Based Agentic Learning), a lightweight post-processing framework that refines diarization outputs without requiring end-to-end model retraining. The framework integrates acoustic analysis, temporal heuristics, and large language model reasoning to identify potential segmentation errors and validate correction decisions through uncertainty-aware filtering and signal-based constraints. A two-stage pipeline combines WavLM speaker embeddings with contextual dialogue understanding to perform conservative merge decisions while preserving transcript integrity. Unlike conventional approaches, CBAL operates as a model-agnostic refinement layer that can be applied to existing diarization systems such as Pyannote and NVIDIA NeMo. Experimental evaluation on the AMI Meeting Corpus demonstrates that the proposed framework achieves

CVPR NTIRE 2026 Not All Pixels Sink: Phase-Guided Representation Learning For Underwater Image Restoration Abhinav Rajput, Saksham Jain, Sparsh Jain, Dinesh Kumar Vishwakarma Underwater images are degraded by color absorption, scattering, and haze, resulting in low contrast, color distortion, and detail loss. This makes reliable restoration vital for marine research and autonomous navigation. To address this, we propose NemoNet, a novel phase-guided representation learning based encoder-decoder architecture. The architecture incorporates the Spectral-Spatial Attention (SSA) block that couples Fourier phase-based pixel refinement with spatial attention to recover fine textures. These details are most severely degraded in underwater conditions and are critical for perceptually convincing restoration more broadly. Phase-based attention in skip connections ensures that they enhance useful representations instead of propagating artifacts. We introduce a hybrid Un/Supervised loss framework, where comprehensive supervised objectives are complemented by an unsupervised color constancy loss that mitigates wavelength-dependent color shifts in underwater scenes. We further introduce a no-reference Color-Plausibility Quality Index (CPQI) that augments Perceptual Index with a color consistency prior, which conventional metrics fail to capture. Comprehensive experiments demonstrate that the proposed approach outperforms existing state-of-the-art methods on supervised (UIEB, LSUI, EUVP) and unsupervised (U45) underwater image datasets across conventional and proposed metrics. ICML ML4AUDlO 2026 FlowFake: Liquid Networks for Audio Deepfake Detection Shivaay Dhondiyal, Diwansh Sharma, Dinesh Kumar Vishwakarma Audio deepfakes generated using modern text-to-speech and voice-cloning systems pose serious threats to speaker authentication, digital media, and online trust. Existing detection methods often perform well only on the datasets they are trained on and struggle to generalize to unseen synthesis techniques. To address this limitation, we propose FlowFake, a lightweight audio deepfake detector based on Liquid Time-Constant (LTC) Networks, which model speech as continuous-time temporal dynamics instead Of fixed-frame sequences. The proposed architecture combines a convolutional feature encoder with an LTC neural ODE module that captures both short-term spectral patterns and long-term prosodic characteristics using adaptive time constants.
